# Glossary

| Term | Definition |
|------|------------|
| Gemeinde | A Swiss municipality. |
| ServiceMention | A record containing a service name and the URLs where the service was found on the Gemeinde website. Produced by Stage 2 (Service Detection). |
| MCP | Model Context Protocol — a standard protocol for exposing data and tools to LLM clients. |
| MCP Resource | A read-only data item exposed by an MCP server. In this project: the Markdown content of a service. |
| MCP Tool | An executable action exposed by an MCP server. In this project: a Python function generated by an LLM that performs an action related to a service (submit a form, query a calendar, download a file). |
| Service Processing | Stage 3 of the pipeline. Reads crawled HTML/PDF files for a service, produces a Markdown summary, and uses an LLM to generate executable Python tool functions. |
| Tool Generation | The step within Service Processing where an LLM analyzes the extracted content and source files, identifies possible user actions, and generates Python code implementing each action as an MCP tool. |
