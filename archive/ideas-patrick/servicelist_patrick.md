| Municipal service                               | What people use it for                                                                      | MCP potential                                                                                                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Moving / residence registration**             | Register arrival, departure or change of address; often via eUmzug.                         | **Very high** — `check_move_requirements()`, `start_move_registration()`, status/checklist tools.                                                          |
| **Resident certificates / confirmations**       | Order Wohnsitzbestätigung, Heimatausweis and similar official confirmations.                | **Very high** — clear inputs/outputs and frequent administrative dependency.                                                                               |
| **Municipal information & contacts**            | Find responsible office, opening hours, phone/email, responsibilities.                      | **Very high** — ideal grounding/tool-routing layer: `find_responsible_office(topic)`.                                                                      |
| **Appointments**                                | Book counter appointments for Einwohnerdienste, civil registry, identity documents, etc.    | **High** — agents can discover slots and prepare users for appointments. Zurich already exposes online appointment-oriented services. ([Kultur Zürich][1]) |
| **Forms / applications**                        | Find the correct form, required documents, fees and submission procedure.                   | **Very high** — probably the broadest generic tool: `get_application_requirements(service)`.                                                               |
| **Building permits / planning applications**    | Submit applications, upload documents, follow proceedings.                                  | **High-value, more complex** — eBaugesucheZH already supports end-to-end electronic procedures in many Zurich municipalities. ([Kanton Zürich][2])         |
| **Public notices / official publications**      | Building applications, council decisions, zoning changes, consultations, elections.         | **Very high** — excellent for structured search, subscriptions and agent monitoring.                                                                       |
| **Waste & recycling**                           | Collection dates, recycling locations, special waste, bulky waste.                          | **Very high** — universally useful and easy to expose as `next_collection(address, type)`.                                                                 |
| **Parking permits**                             | Resident parking permits, visitor permits, renewals and payments.                           | **High** in cities/larger municipalities; Zurich specifically lists parking cards among its online services. ([Stadt Zürich][3])                           |
| **Taxes**                                       | Tax deadlines, invoices/payments, account status, forms, sometimes filing-related services. | **High**, but usually canton/municipality split. Zurich's portal includes online tax administration. ([Stadt Zürich][4])                                   |
| **Childcare / school**                          | Kindergarten/school registration, daycare/Hort applications, holiday care.                  | **High** — highly useful multi-step workflows; Zurich exposes childcare-related services through its account. ([Stadt Zürich][4])                          |
| **Civil status**                                | Marriage appointments, birth/death documentation, civil-status certificates.                | **High** — predictable workflow with document requirements and appointments. Zurich offers these digitally. ([Kultur Zürich][1])                           |
| **Dog registration / dog tax**                  | Register dogs, report ownership changes, fees, local rules.                                 | **Medium-high** — surprisingly good MCP service because rules differ locally.                                                                              |
| **Events / room / facility reservations**       | Reserve sports halls, community rooms, BBQ areas, cultural spaces.                          | **High** — availability + booking maps naturally to agent tools.                                                                                           |
| **Local permits**                               | Events, street use, signage, outdoor dining, markets, amplified sound, temporary closures.  | **High** — agents could determine _which permits a proposed activity requires_.                                                                            |
| **Political / civic information**               | Council meetings, agendas, minutes, voting information and municipal legislation.           | **Very high** for PublicAI — especially structured search over authoritative primary sources.                                                              |
| **Municipal finances / statistics / open data** | Budgets, accounts, population, construction, mobility, environment.                         | **Very high** for your project — better exposed as typed/queryable tools than as generic RAG.                                                              |
| **Report a problem / defect**                   | Broken streetlights, graffiti, damaged roads, illegal dumping, etc.                         | **Very high** — natural agent action: categorize → locate → route → submit.                                                                                |
| **Emergency / local alerts**                    | Road closures, water interruptions, construction, hazards, service disruptions.             | **High** — particularly useful as subscribable/event-driven MCP resources.                                                                                 |
