# Municipal service ideas: historical scope

The early brainstorming covered moving, certificates, contacts, appointments,
forms, permits, public notices, waste and recycling, taxes, schools, civil status,
facilities, civic information, local alerts, and problem reporting. These are
possible service categories, not a verified catalogue of any municipality.

The implemented factory exposes only the six read-only capabilities listed in
[README.md](../README.md#six-stable-tools). It does not book appointments,
submit applications, take payments, subscribe to alerts, or query live account
status. Additional service categories would require new contracts, acquisition,
evidence rules, runtime behavior, and validation.
